# Keyboard Shortcuts

## Tools

| Key | Action |
|---|---|
| **V** | Select / Move tool |
| **A** | Add Point tool |
| **D** | Delete tool |
| **R** | Rectangle tool |
| **T** | Triangle tool |
| **E** | Ellipse tool |
| **S** | Smooth selected points |
| **C** | Corner selected points |

## View

| Key | Action |
|---|---|
| **F** | Fit view to canvas |
| **G** | Toggle grid snap |
| **Alt+G** | Toggle background snap |
| **Scroll** | Zoom in / out |
| **Middle-drag** | Pan |

## Editing

| Key | Action |
|---|---|
| **Shift+click** | Add to selection |
| **Drag** | Marquee select (in Select mode) |
| **Alt+click** | Add point (in any mode) |
| **Ctrl+drag handle** | Break tangent symmetry |
| **Alt+drag handle** | Restore tangent symmetry |
| **Delete / Backspace** | Delete selected points |
| **Escape** | Deselect / close modal |

## Transform Gizmo (2+ points selected)

| Interaction | Action |
|---|---|
| Drag corner handle | Scale |
| Drag corner + **Shift** | Uniform scale |
| Drag corner + **Ctrl+Shift** | Scale around centroid |
| Drag rotation handle | Rotate freely |
| Drag rotation handle + **Shift** | Snap rotation to 15° increments |
| Drag centroid handle | Translate selection |

## History

| Key | Action |
|---|---|
| **Ctrl+Z** | Undo |
| **Ctrl+Y** | Redo |
